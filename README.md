# 원더랜드 랜덤 디펜스

독립 제작한 세로형 HTML5 Canvas 랜덤 디펜스 게임입니다. 설치/빌드/서버 없이 `wonderland.html`을 열면 실행됩니다. 모바일 터치와 PC 마우스 모두 지원합니다.

## 조작
- **소환**: 보석 2개로 수호자 1명을 무작위 소환합니다.
- **합성**: 같은 종류·같은 등급의 수호자 3명을 상위 등급 1명으로 합성합니다.
- **강화**: 골드를 사용해 전체 공격력을 높입니다.
- **마법**: 모든 적에게 피해와 둔화를 가합니다. 재사용 대기시간이 있습니다.
- **자동 소환**: 자원이 충분하고 자리가 있을 때 자동 소환합니다.
- **속도/일시정지**: 게임 속도를 조절하거나 멈춥니다.
- **도감**: 유닛과 규칙을 확인합니다.
- **음악과 효과음**: 첫 게임 조작 후 오리지널 전투 음악을 재생합니다. 상단 음표 버튼으로 음악과 효과음을 켜거나 끕니다.
- **새 게임**: 현재 진행을 지우고 다시 시작합니다.

웨이브를 버티며 5웨이브마다 등장하는 보스를 막으세요. 적이 출구에 도달하면 생명이 감소합니다. 진행 상황은 서버 전송 없이 각 브라우저 프로필에 별도로 저장됩니다. 다른 기기나 브라우저에는 저장 내용을 동기화하지 않습니다.

## 저작권
이 프로젝트의 코드와 게임용 그래픽 표현은 새로 작성되었습니다. 루이스 캐럴의 1865년 소설 《이상한 나라의 앨리스》의 퍼블릭 도메인 등장인물 및 모티프를 사용하였으며, 디즈니 등의 현대적 시각 디자인은 사용하지 않았습니다. 수호자 초상화, 적, 장미 정원 전장은 `art.js`의 오리지널 Canvas 일러스트입니다. 외부 이미지나 폰트 다운로드 없이 실행되며, 기기의 동작 줄이기 설정을 따릅니다. 원본 digi-tamer 소스와 리소스는 포함하지 않습니다.

## 배포
GitHub Pages에서는 저장소의 루트에 다섯 파일(`index.html`, `style.css`, `art.js`, `audio.js`, `game.js`)을 올리고 Settings → Pages에서 main 브랜치 루트를 선택하면 됩니다. 개인 저장소가 비공개인 경우 Pages 제공 여부는 계정 플랜과 설정에 따라 다릅니다.

## 즌다 원정대

기본 주소의 [`index.html`](index.html)은 즌다 원정대 비영리 팬게임을 실행합니다. 기존 원더랜드는 [`wonderland.html`](wonderland.html)에서 플레이할 수 있습니다. 첫 동료 선택, 무작위 영입, 2인 합성과 매 웨이브 보급품 선택을 활용해 32웨이브에 도전합니다. 4웨이브마다 보스가 등장합니다. 원더랜드와 원정대의 저장은 분리되며, 전투 중 다시 로드하면 해당 웨이브부터 시작합니다.

즌다 프로젝트 캐릭터 및 일러스트 권리: 도호쿠 즌코·즌다몬 프로젝트(SSS LLC.), 캐릭터 디자인: 江戸村ににこ. [공식 일러스트](https://zunko.jp/con_illust.html)는 게임에 포함되며 [공식 가이드라인](https://zunko.jp/guideline.html)에 따라 비영리로 제공합니다. 추가 영입 캐릭터 24종은 이 게임용으로 만든 애니메이션풍 일러스트를 사용합니다.

원정대에는 영입 캐릭터 35종과 조합 몬스터 64종이 있습니다. 조합표에서 재료·효과를 확인할 수 있고, 동료 카드 두 장을 눌러 공격 위치를 바꿀 수 있습니다. 보급소에서 지정 영입, 목록 갱신, 편성 확장, 별 등급 훈련, 간식 폭풍 충전에 보석을 사용합니다. 4웨이브마다 전장이 바뀌며, 원정대 보스가 출구에 닿으면 원정이 종료됩니다.

일부 웨이브의 파수대와 모든 보스는 돌진 방패를 두릅니다. 예고가 뜨면 **돌진 저지**를 눌러 방패를 부수세요. 시간이 얼마 남지 않았을 때 저지하면 충격파와 보너스 보석을 받습니다. 보스는 체력이 줄면 방패를 한 번 재생하며, 제한 시간은 전투 배속에 영향을 받지 않습니다.

출전 한도는 8명에서 시작하며 12명까지 확장됩니다. 추가 영입은 대기열로 들어가며, 최대 40명을 보유하고 대기 중인 동료도 합성과 조합에 사용할 수 있습니다. 동료를 선택한 뒤 전장의 빈 배치 위치를 눌러 옮길 수 있습니다. 17웨이브부터는 길이 반전된 심층 전장에 진입합니다.

사각 외곽로를 돌아 내곽과 중앙으로 이어지는 방어 경로를 사용합니다. 5웨이브부터 대열 사이에 회복병이 끼어들며, 공격 대상을 선두·회복병·보스로 바꿀 수 있습니다. 매 웨이브의 전술 포인트 2개로 포격·결빙·방어막 중 필요한 전술을 사용하세요. 오리지널 동료 24종은 공격 순간에 전용 자세를 표시합니다.
