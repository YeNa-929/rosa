# 원더랜드 랜덤 디펜스

독립 제작한 세로형 HTML5 Canvas 랜덤 디펜스 게임입니다. 설치/빌드/서버 없이 `index.html`을 열면 실행됩니다. 모바일 터치와 PC 마우스 모두 지원합니다.

## 조작
- **소환**: 보석 2개로 수호자 1명을 무작위 소환합니다.
- **합성**: 같은 종류·같은 등급의 수호자 3명을 상위 등급 1명으로 합성합니다.
- **강화**: 골드를 사용해 전체 공격력을 높입니다.
- **마법**: 모든 적에게 피해와 둔화를 가합니다. 재사용 대기시간이 있습니다.
- **자동 소환**: 자원이 충분하고 자리가 있을 때 자동 소환합니다.
- **속도/일시정지**: 게임 속도를 조절하거나 멈춥니다.
- **도감**: 유닛과 규칙을 확인합니다.
- **새 게임**: 현재 진행을 지우고 다시 시작합니다.

웨이브를 버티며 5웨이브마다 등장하는 보스를 막으세요. 적이 출구에 도달하면 생명이 감소합니다. 진행 상황은 브라우저 localStorage에 자동 저장됩니다.

## 저작권
이 프로젝트의 코드와 게임용 그래픽 표현은 새로 작성되었습니다. 루이스 캐럴의 1865년 소설 《이상한 나라의 앨리스》의 퍼블릭 도메인 등장인물 및 모티프를 사용하였으며, 디즈니 등의 현대적 시각 디자인은 사용하지 않았습니다. 사용된 그림은 시스템 이모지 및 Canvas 기본 도형으로, 기기마다 표시가 달라질 수 있습니다. 원본 digi-tamer 소스와 리소스는 포함하지 않습니다.

## 배포
GitHub Pages에서는 저장소의 루트에 세 파일(`index.html`, `style.css`, `game.js`)을 올리고 Settings → Pages에서 main 브랜치 루트를 선택하면 됩니다. 개인 저장소가 비공개인 경우 Pages 제공 여부는 계정 플랜과 설정에 따라 다릅니다.
